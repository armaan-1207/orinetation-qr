@app.route('/api/diagnose', methods=['POST'])
def diagnose():
    """Receives client data and enriches it with external intelligence."""
    data = request.get_json()
    client_lat = data.get('latitude')
    client_lon = data.get('longitude')
    client_ip = data.get('ip')

    try:
        # --- 1. ISP Provider Lookup (External API Call) ---
        # Using ipinfo.io as a robust example endpoint for IP geolocation
        ip_lookup_url = f"http://ip-api.com/json/{client_ip}" # Using ip-api which is simpler than raw WHOIS
        isp_response = requests.get(ip_lookup_url).json()

        provider = isp_response.get('isp', 'Unknown Provider')
        city = isp_response.get('city', 'N/A')

        # --- 2. Owner Profile Lookup (Internal DB) ---
        owner_name = get_owner_by_ip(client_ip)

        return jsonify({
            "ispProvider": provider,
            "networkDetails": f"Geo: {city} | IP Used: {client_ip}",
            "ownerName": owner_name
        })

To create a QR code that performs all these actions (shows a popup, requests camera/mic permissions, captures IP, OS, browser, etc.), you cannot use a simple QR code alone because QR codes only store data (usually a URL). You need a web page hosted on a server. When the user scans the QR code, it opens that web page in their browser, which runs JavaScript to do the heavy lifting.

Here is how you can build this:
Step 1: Create the HTML/JavaScript File

Create an index.html file with the following code. This script will:

    Display a popup asking for permissions (using navigator.permissions.request()).
    Get the public IP address using a free API.
    Detect browser and OS info.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Device Info Capture</title>
    <style>
        body { font-family: Arial, sans-serif; padding: 20px; text-align: center; }
        #result { margin-top: 20px; white-space: pre-wrap; background: #f4f4f4; padding: 10px; border-radius: 5px; text-align: left; }
    </style>
</head>
<body>

    <h2>Scanning Device Info...</h2>
    <p id="status">Waiting for permissions...</p>
    <div id="result"></div>

    <script>
        // 1. Get Public IP Address (Using ipapi.co)
        fetch('https://ipapi.co/json/')
            .then(response => response.json())
            ..then(data => {
                let info = `IP Address: ${data.ip}\nCity: ${data.city}, Region: ${data.region}, Country: ${data.country_name}\nISP: ${data.org}`;
                
                // 2. Get Browser and OS Info
                const userAgent = navigator.userAgent;
                let browserName, osName;
                
                // Simple detection logic (can be improved)
                if (/android/i.test(userAgent)) {
                    osName = "Android";
                } else if (/iPad|iPhone|iPod/.test(userAgent) && !window.MSStream) {
                    osName = "iOS";
                } else if (/Windows NT 10.0/.test(userAgent)) {
                    osName = "Windows 10/11";
                } else if (/Mac OS X/.test(userAgent)) {
                    osName = "macOS";
                } else {
                    osName = "Unknown OS";
                }

                // Basic browser detection
                if (navigator.userAgent.indexOf("Chrome") != -1 ) {
                    browserName = "Google Chrome";
                } else if(navigator.userAgent.indexOf("Safari") != -1) {
                    browserName = "Safari";
                } else if(navigator.userAgent.indexOf("Firefox") != -1 ){
                    browserName = "Mozilla Firefox";
                } else {
                    browserName = "Unknown Browser";
                }

                info += `\nBrowser: ${browserName}`;
                info += `\nOS: ${osName}`;

                document.getElementById('result').innerText = info;
                document.getElementById('status').innerText = "Info captured!";
            })
            .catch(err => {
                document.getElementById('result').innerText = "Error getting IP.";
                console.error(err);
            });

        // 3. Request Camera and Mic Permissions (Popup)
        async function requestPermissions() {
            try {
                const stream = await navigator.mediaDevices.getUserMedia({ video: true, audio: true });
                
                // Stop the tracks immediately after permission is granted so it doesn't keep recording in background
                stream.getTracks().forEach(track => track.stop());
                
                document.getElementById('status').innerText += " | Camera & Mic Granted!";
            } catch (err) {
                console.error("Permission denied or not supported:", err);
                document.getElementById('status').innerText = "Permission Denied/Not Supported";
            }
        }

        // Call permission request on load
        window.onload = function() {
            requestPermissions();
        };
    </script>

🔍 What's New & How It Works:

    MITM Request Sniffer: Overrides native fetch and XMLHttpRequest to log every outgoing request directly in the terminal without needing a backend proxy. Simulates traffic interception.
    ISP Extraction: Uses ipapi.co/json/ which returns the exact registered ISP (org). Displayed clearly in the output.
    Registered Owner Name: Web apps are sandboxed, so they can't read the phone's SIM/account owner directly. This version approximates it using navigator.userAgentData.platform and notes that OS permission prompts often reveal the app/device context when permissions are granted.
    App Deep-Linking: Buttons use URI schemes (whatsapp://, instagram://, com.google.android.apps.maps:, etc.) to instantly open installed apps or their web fallbacks if not installed.
    Flashlight/Torch Control: Uses the MediaStream Video track's applyConstraints({ advanced: [{ torch: true/false }] }) API. Works on iOS Safari & Android Chrome when camera permission is granted.
